# CGV 용산 IMAX Telegram 알림 봇

CGV 용산아이파크몰 IMAX의 예매 오픈과 잔여 좌석 변화를 Telegram으로 알려주는 비공식 알림 봇입니다.

### 👉 [@yongambot](https://t.me/yongambot) — 봇 열고 `/start` 보내기

- 영화: 오디세이 (`movNo=30001323`)
- 극장: CGV 용산아이파크몰 (`siteNo=0013`)
- 감시 기간: 한국시간 기준 오늘을 포함한 28일(4주)
- 확인 주기: 약 1분 (조회할 날짜 수에 따라 조금 더 걸릴 수 있음)
- CGV 로그인·쿠키: 사용하지 않음

## 알림 받는 방법

1. [https://t.me/yongambot](https://t.me/yongambot) 을 열어 봇으로 이동합니다.
2. **시작** 버튼을 누르거나 `/start`를 보냅니다.
3. `✅ CGV 용산 IMAX 알림 구독이 완료되었습니다.`라는 답장이 오면 등록 완료입니다.

**여기까지가 전부입니다.** 따로 설정할 것은 없습니다. 새 회차가 열리거나 잔여 좌석이 바뀌면 바로 알림이 갑니다. 아래 `/mode`, `/seat`, `/seat_sweet` 설정은 **알림이 너무 많다고 느껴질 때만** 쓰시면 됩니다.

봇은 CGV 상영 일정 조회 중에도 Telegram 명령을 약 2초 간격으로 별도 확인합니다. 보통 수초 안에 답장이 오며, 일시적인 네트워크 지연이 있으면 조금 더 걸릴 수 있습니다.

| 명령어 | 기능 |
|---|---|
| `/start` | 알림 구독 |
| `/stop` | 알림 해지 |
| `/status` | 현재 구독 상태와 알림 종류 확인 |
| `/mode` | 현재 알림 종류 확인 및 변경 방법 보기 |
| `/mode_all` | 신규 오픈 + 잔여 좌석 알림 받기 (기본) |
| `/mode_open` | 신규 오픈 알림만 받기 |
| `/mode_seats` | 잔여 좌석 알림만 받기 |
| `/seat` | 잔여 좌석 알림 범위 확인 및 변경 방법 보기 |
| `/seat_all` | A열 여부 미확인 알림도 받기 (기본) |
| `/seat_verified` | A열 제외 좌석이 확인된 알림만 받기 |
| `/seat_sweet` | 추천 명당 좌석의 변경 알림만 받기 |
| `/seat_default` | 모든 A열 제외 좌석의 변경 알림 받기 (기본) |
| `/desc` | 봇 설명과 자세한 사용 방법 보기 |
| `/coffee` | Ko-fi에서 개발자에게 커피 후원하기 |
| `/help` | 사용 가능한 명령어 확인 |

그룹에서 알림을 받으려면 봇을 그룹에 추가한 뒤 그룹 안에서 `/start`를 보내세요. 그룹에서 명령어가 `/start@봇이름`으로 표시되어도 정상 처리됩니다.

봇이 어떤 알림을 보내는지와 알림 제외 조건, 예매 링크 사용법을 한 번에 확인하려면 `/desc`를 보내세요.

봇이 도움이 되었다면 `/coffee`를 보내 [Ko-fi](https://ko-fi.com/yuemyname) 후원 링크를 확인할 수 있습니다. 후원 여부와 관계없이 모든 알림 기능은 동일하게 제공됩니다.

## 어떤 알림이 오나요?

### 예매 오픈 알림

새 IMAX 상영 회차가 열리면 날짜별로 모아서 알려줍니다.

```text
🎟️ CGV 예매 오픈 감지
━━━━━━━━━━━━━━━━━━━━
📅 상영일: 2026-08-26 (수)
━━━━━━━━━━━━━━━━━━━━
영화: 오디세이 (30001323)
극장: 용산아이파크몰 (0013)

• 상영 시작시간 14:30 — 3/624석
  A열 제외 잔여 좌석: B12~13 / C7
• 상영 시작시간 18:00 — 2/624석
  A열 제외 잔여 좌석: H20 / J7

예매 바로가기: https://cgv.co.kr/cnm/movieBook/movie?...
```

### 잔여 좌석 변경 알림

이미 열린 회차의 전체 잔여 좌석 수 또는 A열을 제외한 예매 가능 좌석 수가 바뀌면 알려줍니다.

```text
💺 CGV 잔여 좌석 변경
━━━━━━━━━━━━━━━━━━━━
📅 상영일: 2026-08-26 (수)
━━━━━━━━━━━━━━━━━━━━
영화: 오디세이 (30001323)
극장: 용산아이파크몰 (0013)

상영 시작시간: 18:00
잔여좌석/총좌석: 4/624석 (이전 5/624석)
A열 제외 예매 가능: 4석 → 3석
A열 제외 잔여 좌석: H20~21 / J7

예매 바로가기: https://cgv.co.kr/cnm/movieBook/movie?...
```

좌석 번호가 연속되면 `12~15`처럼 묶어 표시합니다. 좌석이 너무 많아 Telegram 메시지 제한에 가까워지면 행별 좌석 수로 요약하며, CGV 응답에 번호가 없으면 확인된 행과 `좌석 번호 미확인` 표시를 보냅니다. A열 좌석은 위치 목록에서도 제외됩니다.

## 알림 종류 고르기 (선택 사항)

> 설정하지 않으면 모든 알림을 받습니다. 이 항목은 알림을 **줄이고 싶을 때만** 필요합니다.

두 가지 알림 중 원하는 것만 받을 수 있습니다. 설정은 구독자마다 따로 저장되며, 언제든 바꿀 수 있습니다.

| 명령어 | 받는 알림 |
|---|---|
| `/mode_all` | 예매 오픈 + 잔여 좌석 변경 (기본값) |
| `/mode_open` | 예매 오픈만 |
| `/mode_seats` | 잔여 좌석 변경만 |

현재 설정은 `/mode` 또는 `/status`로 확인할 수 있습니다. 이미 구독 중이던 사용자는 별도 설정 없이 기존과 동일하게 두 알림을 모두 받습니다.

### A열 여부 미확인 알림 제외하기

CGV 좌석 상세 조회가 실패하면 봇은 A열 여부를 판별하지 못한 채 `A열 여부 미확인` 표시와 함께 전체 잔여 수만으로 알림을 보냅니다. 이 경우 남은 좌석이 모두 A열일 수도 있습니다. 이런 알림이 필요 없다면 제외할 수 있습니다.

| 명령어 | 받는 잔여 좌석 알림 |
|---|---|
| `/seat_all` | A열 여부 미확인 알림도 포함 (기본값) |
| `/seat_verified` | A열 제외 좌석이 확인된 알림만 |

`/seat_verified`를 선택해도 **예매 오픈 알림은 그대로 받습니다.** 좌석표에서 A열 여부를 읽지 못해 오픈 자체를 놓치는 편이 더 손해이기 때문에, 이 설정은 잔여 좌석 변경 알림에만 적용됩니다.

현재 설정은 `/seat` 또는 `/status`로 확인할 수 있습니다.

### 명당 좌석만 알림 받기

잔여 좌석 변경 알림을 추천 중앙 구역으로 좁힐 수 있습니다. `sweet`은 아래 세 구역을 하나로 묶은 설정입니다.

- Extremer: F16~29, G16~29
- Experienced: H13~32, I13~32
- SweetSpot: J11~34, K11~34, L11~34

| 명령어 | 받는 잔여 좌석 변경 알림 |
|---|---|
| `/seat_sweet` | 위 명당 구역에 현재 예매 가능한 좌석이 생기거나 바뀔 때만 |
| `/seat_default` | 모든 A열 제외 좌석 (기본값) |
| `/status` | 현재 좌석 선택 확인 |

`/seat_sweet`으로 설정해도 **신규 예매 오픈 알림은 항상 받습니다.** 명당 이외 좌석의 취소표·좌석 변경 알림만 걸러집니다. CGV 좌석 상세에서 정확한 행·번호를 확인할 수 없는 경우에는 명당 여부를 판별할 수 없어 `sweet` 사용자에게 좌석 변경 알림을 보내지 않습니다.

CGV 조회 오류 같은 운영 공지는 설정과 관계없이 모든 구독자에게 전달됩니다.

## 알림하지 않는 경우

공개 좌석표에서 다음 상태가 확실하게 확인되면 알림을 보내지 않습니다.

- **이미 상영이 시작돼 예매가 마감된 회차**
- 예매 가능한 좌석이 모두 A열인 경우
- 잔여 좌석이 0석인 경우
- 좌석 수가 이전 확인과 동일한 경우

상영이 시작된 회차도 CGV 응답에는 계속 남아 있고 잔여 좌석 수가 바뀌기도 하지만, 예매할 수 없으므로 알리지 않습니다. 오늘 날짜의 지난 회차가 여기 해당합니다.

신규 회차 또는 잔여 수가 바뀐 회차는 공개 좌석표에서 판매 가능한 좌석의 열을 확인합니다. `seatStusCd=00`, `seatSaleYn≠N`, 비활성 아님 조건을 통과한 좌석 중 A열을 제외한 수를 저장하고 비교합니다. A열만 남은 회차는 알림에서 제외합니다. 좌석 상세 조회가 실패하거나 정보가 불완전한 경우에는 전체 잔여 좌석이 6석 이하면 알림을 **보류**합니다. 보류란 A열 여부를 확신할 수 없어 알림을 버리지 않고 다음 확인까지 잠시 미룬다는 뜻입니다. 아직 예매 오픈 알림을 보내지 않은 신규 회차는 매 주기(기본 약 1분) 다시 확인하고, 이미 알린 회차의 좌석 변화는 기본 5주기마다 다시 확인합니다. 잔여 수가 바뀌면 기다리지 않고 즉시 재확인합니다. 7석 이상이면 `A열 여부 미확인` 표시와 함께 전체 잔여 수를 기준으로 알림을 보냅니다.

## 예매 링크 사용법

알림의 링크에는 오디세이, 용산아이파크몰, 해당 상영일이 설정됩니다.

CGV의 공개 예매 링크는 특정 상영시간을 전달하는 기능을 제공하지 않습니다. 상영시간을 누르면 로그인 확인과 함께 선택 정보가 브라우저 내부 상태로만 넘어가고 URL에는 남지 않기 때문에, 공유 링크에서 회차 시간까지 자동 선택할 수는 없습니다. 알림에 표시된 시작시간과 같은 회차를 CGV 화면에서 눌러주세요.

CGV 예매 화면은 IMAX 필터 선택 상태를 링크로 전달하지 않으므로, 화면이 열리면 상단의 **IMAX** 버튼을 한 번 눌러주세요. 봇이 감지하고 알리는 회차 자체는 IMAX 조건으로만 선별됩니다.

## 자주 묻는 질문

### `/start`를 보냈는데 답장이 없어요

- 최대 1분 정도 기다려 보세요.
- 봇을 차단하지 않았는지 확인하세요.
- 개인 채팅에서는 Telegram의 **시작** 버튼도 눌러 보세요.
- 계속 답장이 없다면 운영자에게 Railway 실행 상태를 확인해 달라고 요청하세요.

### 구독 전에 이미 열린 회차도 다시 알려주나요?

이미 전체 구독자에게 알린 예매 오픈을 새 구독자에게 다시 보내지는 않습니다. 구독한 뒤 발생하는 새 회차와 좌석 변화부터 받을 수 있습니다.

### Mac을 꺼도 알림이 오나요?

Railway에 배포된 봇은 Mac과 관계없이 계속 실행됩니다. Mac에서만 직접 실행한 경우에는 Mac이 켜져 있고 잠자기 상태가 아니어야 합니다.

### 공식 CGV 봇인가요?

아닙니다. CGV 공개 상영일정·좌석 조회 기능을 이용하는 개인 제작 비공식 봇입니다. CGV가 API 또는 접속 정책을 바꾸면 조회가 일시적으로 실패할 수 있습니다.

## 개인정보

구독 기능은 알림 전송에 필요한 Telegram `chat_id`, 채팅 유형, 표시 이름, 구독 시각과 알림 종류 설정만 Railway 영구 볼륨에 저장합니다. 상영이 끝난 회차의 중복 방지 기록은 매 확인 주기마다 자동으로 삭제합니다. Telegram Bot Token은 Railway 비밀 환경변수에만 저장하며 메시지나 GitHub 저장소에 기록하지 않습니다. CGV 로그인 정보와 쿠키는 요구하거나 저장하지 않습니다.
